# ATM Banking Application

## Overview

This project is a Python-based ATM Banking Application developed using Tkinter for the graphical user interface. The system introduces a cardless ATM concept where users authenticate using a unique username and password instead of a physical ATM card.

The objective is to enhance security by eliminating risks associated with lost, stolen, cloned, or damaged ATM cards while also reducing the operational costs incurred by banks for card manufacturing, maintenance, and postal delivery.

## Key Features

- Secure username and password authentication
- Cardless ATM access
- Balance inquiry
- Cash withdrawal
- Cash deposit
- Transaction validation
- User-friendly Tkinter GUI
- Reduced dependency on physical banking cards

## Advantages

- Minimizes ATM card theft and misuse
- Eliminates card cloning and skimming attacks
- Reduces card production costs for banks
- Removes postal and replacement card expenses
- Provides convenient and accessible banking services

## Technologies Used

- Python
- Tkinter
- File Handling / Database Management
- Object-Oriented Programming
